# Demo Notes

## Case A：准备加盟奶茶店

目标：演示开店前潜力分析。

关键输入：

- 总投资 420000 元。
- 自有资金 180000 元。
- 负债 240000 元。
- 月租金 26000 元。
- 加盟费 120000 元。
- 商场位置，同商圈竞品 12 家。

预期展示点：

- Agent 先算预估日营收和日毛利。
- 风险集中在负债、租金、加盟投入和竞品密度。
- 输出不是“能开/不能开”的简单判断，而是补充调研动作。

## Case B：已开面馆经营诊断

目标：演示开店后经营诊断。

样例数据：

- `orders.csv`
- `menu_items.csv`
- `reviews.csv`

预期展示点：

- 总营收、订单数、客单价由 pandas 工具计算。
- 菜品矩阵识别明星菜品、引流菜品、利润菜品和问题菜品。
- 评论主题识别配送、包装、出餐慢等问题。
- Agent 将指标、证据和行动建议组合成报告。
