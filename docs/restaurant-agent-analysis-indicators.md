# 餐饮门店分析 Agent 指标体系

本文档定义本项目需要分析的完整指标范围。指标分为两类：

- 数据型指标：可以从订单、成本、评论、外卖、排班、财务等数据中计算。
- 抽象型指标：需要通过店主问答、现场照片、商圈描述、合同/加盟资料等信息判断。

项目第一版不需要全部实现，但 Agent 的诊断框架应覆盖这些维度，后续按 MVP 优先级逐步落地。

## 0. 业务模块划分

本项目建议拆成两个清晰业务模块：

### 模块 A：开店前潜力分析

目标用户是准备开店、正在选址、正在看加盟项目、正在评估品类的人。

核心问题：

- 这个店能不能开？
- 这个位置适不适合这个品类？
- 投资额是否过高？
- 保本线是否现实？
- 加盟品牌是否可靠，是否有快招风险？
- 店主的资金、经验、执行能力是否匹配？
- 最坏情况下亏损是否可承受？

主要输入：

- 店主问卷
- 预算表
- 租赁条件
- 商圈信息
- 竞品观察
- 加盟资料
- 品类计划
- 菜单与定价设想
- 门店照片或视频

核心输出：

- 开店可行性评分
- 商圈匹配度
- 品类匹配度
- 投资风险等级
- 加盟/快招风险判断
- 预估保本营业额
- 预估回本周期
- 是否建议开店
- 需要补充调研的问题
- 降低风险的调整方案

### 模块 B：开店后经营诊断

目标用户是已经开店、正在亏损、增长乏力、想优化菜单/外卖/营销/成本的人。

核心问题：

- 这家店现在能不能活？
- 为什么不赚钱？
- 营收下降是订单、客单、渠道、菜品还是口碑导致的？
- 哪些菜品应该保留、优化、涨价或下架？
- 外卖是否真的赚钱？
- 人工、房租、食材、活动成本哪一项最危险？
- 应该继续整改、观察，还是及时止损？

主要输入：

- 订单 CSV
- 菜品成本 CSV
- 外卖订单 CSV
- 顾客评论 CSV
- 排班表
- 房租与固定成本表
- 活动记录
- 会员数据
- 店主补充问答

核心输出：

- 经营健康度评分
- 盈亏诊断
- 营收下滑归因
- 菜品四象限
- 外卖盈利分析
- 差评主题分析
- 成本压力分析
- 现金流预警
- 整改行动清单
- 观察周期与止损条件

两个模块共享同一套指标字典，但分析顺序不同：开店前偏“可行性预测与风险排雷”，开店后偏“经营复盘与整改决策”。

## 18. Agent 诊断顺序

Agent 首先判断用户处于哪个业务阶段：

- 开店前：走“潜力分析”流程。
- 开店后：走“经营诊断”流程。
- 信息不足：先追问当前状态，例如“已经开店了吗？”、“是否已有订单数据？”、“是否正在评估位置或加盟项目？”。

### 18.1 开店前潜力分析顺序

1. 先判断开店阶段：只是想法、已选品类、已看位置、已签合同、已交加盟费。
2. 再看投资背景：总投资、负债、流动资金、可承受亏损月份。
3. 再算预估生存线：房租、人工、食材、保本营业额、保本订单数。
4. 再看商圈：客流质量、目标客群、竞品密度、门头可见性、租金合理性。
5. 再看品类：消费频次、毛利空间、操作难度、是否适合本地客群。
6. 再看加盟：品牌真实性、直营店、加盟商反馈、快招风险、合同风险。
7. 再看店主能力：经验、算账能力、执行能力、是否全职、是否有风险预案。
8. 最后给结论：建议开、调整后再开、继续调研、不建议开、立即停止投入。

### 18.2 开店后经营诊断顺序

Agent 分析时应优先按以下顺序执行：

1. 先算生存线：是否能覆盖固定成本。
2. 再拆收入：是订单少、客单低、时段弱，还是渠道结构差。
3. 再拆成本：是房租、人工、食材、佣金、活动补贴哪一项压垮利润。
4. 再看菜品：哪些菜赚钱，哪些菜拖累，哪些菜影响出餐和口碑。
5. 再看口碑：差评集中在哪里，是否对应经营数据异常。
6. 再看商圈：产品、价格、位置和客群是否匹配。
7. 再看加盟/投资背景：是否有快招风险、债务压力和沉没成本误判。
8. 最后给结论：可救、观察、止损或不建议开。
