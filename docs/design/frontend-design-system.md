# Market Pilot 前端设计系统

> 状态：2026-08-24 已在经营诊断报告页落地。设计依据来自 UI/UX Pro Max 的定向检索，并经过业务适配过滤，不直接采用自动生成结果。

## 1. 产品形态

Market Pilot 是供餐饮经营者反复查看、比较和采取行动的经营工作台，不是营销落地页，也不是长篇咨询报告。页面优先级固定为：

1. 当前经营状态与关键财务指标；
2. 可核验的趋势、成本、菜品和渠道证据；
3. Agent 规划、工具和降级轨迹；
4. 风险、行动和追问入口。

## 2. 视觉原则

- 使用高密度但可扫描的 12 栏桌面网格，模块间距为 12px。
- 工具面板使用 6px 圆角、1px 边框和极弱阴影，不使用装饰性卡片墙。
- 中文正文使用系统无衬线字体，避免依赖不覆盖中文的外部字体。
- 绿色表示稳定或正向经营状态，琥珀表示关注，红色表示亏损或高风险，蓝色仅用于中性信息。
- 标题服务于定位，不占据完整首屏；首屏必须同时露出核心指标和至少一个分析模块。
- 动效只用于状态变化、展开和交互反馈，并尊重 `prefers-reduced-motion`。

## 3. 核心 Token

| Token | 值 | 用途 |
| --- | --- | --- |
| `--success` | `#176b4b` | 盈利、稳定、执行成功 |
| `--warning` | `#a16207` | 接近保本线、需要关注 |
| `--danger` | `#b42318` | 亏损、高风险、负向指标 |
| `--info` | `#2463a6` | 中性信息与辅助分类 |
| `--report-line` | `#dce4e0` | 报告模块边界 |
| `--report-shadow` | `0 1px 2px rgb(20 38 30 / 4%)` | 工具面板轻量层级 |

## 4. 数据表达规则

- 少于 4 个营业日时展示离散柱图，不声称形成长期趋势；达到 4 个营业日后才使用折线图。
- 菜品销量与毛利必须表达为明星、引流、利润、问题四象限，不能退化为同质卡片列表。
- 渠道比较优先使用排序表格或条形图，保留营收、费用和贡献利润的精确数值。
- 所有风险指标同时显示文字，不能只依赖颜色。
- 图表必须提供直接标签、Tooltip 或等价的数据列表，并保持键盘可访问。

## 5. 响应式规则

- `> 980px`：12 栏工作区，首屏 6 项核心指标。
- `641px - 980px`：模块单列，核心指标三列两行。
- `<= 640px`：核心指标两列三行，四象限改为单列，报告状态与 Agent 轨迹纵向排列。
- 最小验收视口为 390x844；页面不得出现横向滚动。

## 6. 明确拒绝

- 企业门户 Hero、销售 CTA 和 Logo 墙；
- 通用蓝色 SaaS 配色或餐饮红金促销配色；
- 大面积米黄色、渐变球和装饰性阴影；
- Bento 卡片墙和无业务含义的动效；
- 将内部 provider、错误码或 `disabled` 等实现细节直接展示给经营者。
