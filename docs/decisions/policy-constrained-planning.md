# ADR: Policy-Constrained Planning

- Status: Accepted
- Date: 2026-08-14

## Context

固定执行全部工具无法体现 Agent 的问题导向能力；让模型任意选工具、参数和循环次数又会
带来成本、稳定性和安全问题。地图能力还包含供应商参数、快照和事务等不应暴露给模型的细节。

## Decision

经营诊断提供 `full` 与 `focused` 两种显式模式。模型只能从按输入可用性生成的工具目录中
选择；策略层校验工具白名单、最小必需集合和一至四个 focused 工具。一次可恢复的必需工具
失败最多触发一次重规划。生命周期路由只选择高层业务能力，选址内部参数由领域服务控制。

## Consequences

- focused 问题能以更少调用完成，同时保留 full 体检的稳定路径。
- 计划可以离线评估 precision、recall 和 exact-set，而不是只评价文案。
- 模型故障、非法计划或证据失败会降级到确定性路径。
- 新工具必须先声明输入、输出、证据和限制，再加入策略目录；不能仅靠修改提示词上线。
